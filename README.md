# ATTDIV LLC - Arquitectura Digital y Planos 3D Online

Sitio web corporativo y plataforma de diseño y elaboración de planos 3D de construcción 100% ONLINE en Estados Unidos.

## Características Técnicas
- **Plataforma 100% Responsiva**: Optimizada para dispositivos móviles, tablets y pantallas de alta resolución.
- **Visor Comparativo Interactivo**: Comparación interactiva y fluida entre Plano Técnico CAD 3D y Render Arquitectónico Fotorrealista.
- **Hotspots Técnicos**: Puntos interactivos con fichas de especificaciones técnicas milimétricas.
- **Paleta de Identidad Visual**:
  - Café: `#603814`
  - Beige: `#c7b199`
  - Tierra: `#736356`
  - Blanco: `#ffffff`
- **Catálogo de Servicios y Portafolio**: Documentación completa de planos arquitectónicos, estructurales y redes MEP.
